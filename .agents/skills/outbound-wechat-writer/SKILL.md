# Outbound WeChat Writer — 一人公司双轨报道与去 AI 味成稿规范

## 1. 隐私与安全硬红线（最优先）

- **私密物理隔离**：凡含 `private: true`、`#私密`、`#private`、`[私密]` 或 `category=私密` 的时间日记条目，**绝不读取入稿、绝不引用暗示**。
- **零密钥泄露**：所有 API Key、Token、真实服务器 IP、本地用户敏感路径一律脱敏。

## 2. 双轨彻底分家（严禁一稿缩略两吃）

| 轨道 | 定位 | 写法铁律 |
| :--- | :--- | :--- |
| **日常切片（朋友圈 / 即刻）** | 一人公司茶水间花絮 / Ship Log | 每次只截 **1 个真实瞬间 + 2～4 行人话**；严禁发 `1️⃣ 2️⃣ 3️⃣ 4️⃣` 版本公告清单。 |
| **公众号深度专栏** | 工程博客 & 单点实战拆解 | **一篇只讲透一个具体痛点或反常识切口**；其余工具仅做顺手提及的内链钩子，绝不写成工作周报。 |

## 3. 去 AI 味五条铁律（对标《字节笔记本》）

1. **线性故事递进，砍掉总分总 PPT 骨架**：按「具体烦人场景 → 试错踩坑/折腾升级 → 反转或实测结论」单线推进，少用嵌套列表。
2. **手机竖屏短句成段**：每段控制在 1～2 句话，段间空行，降低拇指滑动阅读阻力。
3. **保留物理颗粒度**：保留真实硬件型号、报错卡点、具体数字，不把鲜活细节洗成“WebSocket 闭环、多维赋能”等抽象词。
4. **保留真性情与自嘲**：承认怕麻烦、走过弯路或“折腾魔障了”，结尾只留 1 句轻巧具体的互动提问。
5. **禁用词黑名单**：禁用「赋能、闭环、抓手、数据飞轮、最后一块拼图、拒绝信息过载、总而言之、综上所述」。

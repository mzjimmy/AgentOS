## 1. 背景与核心问题

时间日记是人类唯一需要长期维护的主线，记录了真实生活、工程与思考语境。如果直接从自己的非私密日记里提炼高价值外语词汇和语法，记忆锚点远强于死背通用词书。

但历史方案（SentinelLab 旧版）存在明显痛点：
- 把整篇日记全部翻译并堆在前台展示，页面臃肿、阅读负担重，用户根本看不完；
- 依赖 PostgreSQL 后端与多套云端配置，无法轻量嵌入本地桌面工作台 AgentOS。

## 2. 产品目标与反模式红线

### 核心目标
1. **后台静默产语料，前台只推精炼互动卡**：每日将非私密日记在后台静默翻译为目标外语语料并按日落盘（仅作归档与例句来源），前台页面只呈现**跨过难度门槛的生词卡片 + 精炼语法点卡片**（默认每日上限 8–10 张）。
2. **极低认知负担的交互**：每张卡片只需单次点击反馈——`已掌握`（整卡下线）、`收藏强化`（直接转正进高频复习）、`稍后再看`（SRS 间隔重排）、`听发音`（一键朗读词与例句）；当天没空看自动攒入待看池，不制造打卡焦虑。
3. **硬隐私过滤**：强制复用 `electron/desk/journal-privacy.ts` 的 `isPrivateJournalEntry` 与 `scrubSecrets`，任何私密条目**绝不翻译、绝不落语料库、绝不出卡**。

### 明确 Non-Goals & Anti-Patterns
- **严禁在前台展示整篇翻译后的日记语料**（仅卡片内附带 1–2 句脱敏自当日语料的上下文例句）。
- **不引入 PostgreSQL / 外部数据库**，全部使用 `~/VibeCoding/SentinelDesk/language/` 本地文件存储。
- **不扩大上游冲突面**：严格遵守 `AGENTS.md` 5 条护栏，不平铺扩写 `electron/main.ts`。

## 3. 动工后效果预演

- AgentOS 左侧顶部固定栏在「时间日记 / 意图待办 / 常用命令」下方新增第 4 个入口 **「外语学习」**（`#language-push`）。
- 点开后顶部显示今日待学数、攒池余量、语种/门槛徽章与「立即生成今日卡片」按钮；主区为清爽的单卡/卡片流视图：
  - 正面给出词条/语法结构、音标/假名、一键发音、简洁中文释义，以及 **1 句来自你真实日记语境的原汁例句**（带回跳原日记日期锚点）；
  - 底部固定 3 个极简反馈按钮：`已掌握` / `收藏强化` / `稍后再看`。
- 不再看到成段机翻日记，每次碎片时间 1–2 分钟刷完 3–5 张即可关闭。

## 4. 开工前需你拍板的 3 个小选项

1. **MVP 主修语种**：`A. 仅英语（推荐，最轻最快上线）` / `B. 英语 + 日语双语` / `C. 英日韩三语`
2. **每日推送卡片预算**：`A. 8 张（6 词 + 2 语法，推荐防过载）` / `B. 12 张（10 词 + 2 语法）`
3. **发音方案**：`A. MVP 先用零配置本机离线发音（Web Speech / macOS say），V1.1 可选云端 TTS（推荐）` / `B. 首版直接接入 SentinelLab 同款云端 TTS`
